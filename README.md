# Store Product Location & Barcode Tracking System 📱🔍

A cross-platform mobile prototype and Web API designed for retail operations to optimize product location discovery and real-time stand updates via barcode scanning.

---

## 🌟 Key Features

- **Barcode Scanning:** Rapid product lookup and inventory verification using mobile camera / barcode scanning.
- **Location Optimization:** Real-time mapping of store stands, aisles, and stock sections.
- **RESTful Web API:** Backend service built to handle database synchronization and live inventory updates.
- **Cross-Platform Support:** Single C# codebase targeting mobile devices for seamless in-store staff usage.

---

## 🛠️ Tech Stack

- **Mobile Framework:** .NET MAUI (C#)
- **Backend:** .NET Web API
- **Database:** Microsoft SQL Server
- **IDE:** Visual Studio

# Mağaza Ürün Konumu ve Barkod Takip Sistemi 📱🔍

Perakende mağaza operasyonlarında ürün yer tespitini hızlandırmak, reyon/stant konumlarını ve stok durumlarını barkod taraması ile anlık güncellemek amacıyla geliştirilmiş mobil uygulama ve Web API prototipi.

---

## 🌟 Öne Çıkan Özellikler

- **Barkod Taraması:** Mobil kamera üzerinden hızlı ürün arama, doğrulama ve stok kartı erişimi.
- **Konum Haritalama:** Mağaza içi stantlar, reyonlar ve depo bölümlerinin anlık konum güncellenmesi.
- **RESTful Web API:** Veritabanı senkronizasyonu ve canlı stok güncellemelerini sağlayan arka plan servisleri.
- **Çoklu Platform Desteği:** Mağaza personelinin saha kullanımına uygun C# .NET MAUI mobil mimarisi.

---

## 🛠️ Kullanılan Teknolojiler

- **Mobil Çerçeve:** .NET MAUI (C#)
- **Arka Yüz (Backend):** .NET Web API
- **Veritabanı:** Microsoft SQL Server
- **Geliştirme Ortamı:** Visual Studio
